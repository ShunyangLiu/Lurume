# v0.0.7 稳定性修复

本轮针对 v0.0.6 代码审查发现的问题，随 v0.0.7 发布。

## 翻译

- 系统翻译在语言可用性检查、资源准备返回后验证取消状态和请求代数。旧请求不能再改写界面，也不能替换新请求的超时任务。
- 识别模型响应的 `length`、`content_filter` 等非正常结束原因。流式与非流式均保留已收到的文本、标记不完整、允许重试，不缓存为成功。
- 修正流末尾没有空行分隔符时漏发最后一段文本的问题。
- XPC 请求和连接身份在同一把锁下管理，旧连接的中断或失效只影响其拥有的请求。

## 笔记与数据保护

- 笔记主文件保存失败时，尝试将恢复草稿原子写入独立的 `note-drafts.json`。
- 再次打开对应笔记时显示恢复提示。未经编辑或明确选择“保存恢复草稿”，关闭卡片不会自动覆盖原笔记；也可选择“保留原笔记”。
- 关闭阅读窗口后，内存草稿仍由应用级阅读控制器持有。退出与更新重启前检查未保存草稿；主文件和草稿都无法写入时明确提示丢失风险，默认返回检查。
- 因草稿而暂缓的更新可以从“继续安装更新…”菜单恢复。
- 文献库和高亮笔记保存前，将上一份已验证的不同快照保存在同目录的 `library.json.previous`、`highlights.json.previous`。无变化的重复保存不会轮换备份；无法读取或验证的主文件不会覆盖已有备份。
- 这是单份历史快照，不是完整版本历史，也不备份原始 PDF。恢复时应先退出应用并另存现有文件，再检查备份内容；不会自动用旧快照覆盖当前数据。
- 单元测试的默认高亮与恢复草稿路径现在与文献库一样隔离到测试临时目录。

## PDF 搜索

使用 PDFKit 异步搜索和可取消的搜索会话，分批发布计数；关键词变化、关闭搜索或切换文档时移除旧监听，拒绝过期结果。保留所有匹配用于导航，同时将普通高亮覆盖层限制在 500 个匹配内。

## 验证与边界

- 回归覆盖旧系统请求迟到、超时保护、截断与过滤响应、旧 XPC 连接迟到回调、草稿恢复与退出拦截、备份保护、异步搜索取消与导航。
- 本地模拟 HTTP 服务覆盖真实嵌入式 XPC 通路，不读取 API Key、不发送真实文献。
- 未进行 Bob 与真实模型服务的同参数速度对照，也没有修改连接复用策略，不能据此宣称真实模型翻译已提速。
- 发布前尚未进行真实 Sparkle 安装替换测试；签名与更新源由既有两阶段发布脚本验证。

本轮在 macOS 15.7.7 上的测试结果：完整测试集 288 项，其中 263 项通过、25 项因未配置外部测试环境跳过、0 失败；另启动回环模拟服务后，翻译 XPC 与网络操作测试 20 项全部通过。新增 18 项回归测试。
