# Lurume P3 阅读导航与文献整理计划

状态：已确认并完成实现前审查，尚未进入实现
更新日期：2026-08-28

## P3 目标

P3 补齐两组基础能力：在长论文中通过目录和页面缩略图快速定位，以及在文献数量增加后通过阅读状态、筛选和排序保持列表可管理。

```text
从文献库选择论文
→ 用目录或页面缩略图定位内容
→ 阅读过程中手动更新阅读状态
→ 用状态筛选、搜索和排序找回论文
```

P3 仍然保持轻量，不扩展为项目管理、标签系统或复杂导航历史。

## 已确认的产品边界

- 阅读导航只包含 PDF 自带目录和页面缩略图。
- 不自动分析正文或生成目录。
- 不记录返回/前进位置历史。
- 文献整理只包含三态阅读状态、状态筛选和四种排序方式。
- 阅读状态完全由用户手动维护，打开论文不会自动改变状态。
- 不在 P3 加入收藏、标签、文件夹、集合或智能集合。
- 原 PDF 仍然只读；目录和缩略图功能不得修改、重排或导出页面。

## 左侧栏模式

左侧栏顶部提供三个互斥模式：

```text
文献 ｜ 目录 ｜ 页面
```

- “文献”显示文献列表、状态筛选、排序、搜索和导入入口。
- “目录”显示当前 PDF 自带的层级目录。
- “页面”显示当前 PDF 的纵向页面缩略图。
- 应用每次冷启动默认进入“文献”，不持久化上次侧栏模式。
- 同一次运行中切换论文时，保留当前侧栏模式并更新为新论文的目录或缩略图。
- 没有选择论文时，“目录”和“页面”显示安静的空状态。
- 切换侧栏模式不改变当前 PDF 页码、选区、译文、检查器模式或高亮状态。

P3 第一版不为这三个模式增加键盘快捷键，待真实使用验证切换频率后再决定。

## PDF 目录

- 目录只读取 PDFKit 提供的 PDF 自带 outline，保留原始层级和标题。
- 有子项的目录节点使用原生展开/折叠交互。
- 点击目录项时选中该项，并跳转到它指向的页面或目标位置。
- P3 只执行当前文档内的 `PDFDestination` 或 `PDFActionGoTo`；外部 URL、远程文档及其他动作不自动执行，对应项显示为不可跳转。
- 普通滚动、逐页翻页、页码输入、PDF 搜索和高亮列表跳转不自动改变目录选择，也不强制滚动目录列表。
- 切换论文时清除旧论文的目录选择，再载入新论文目录。
- PDF 没有目录时显示“这份 PDF 没有目录”一类的轻量空状态，不尝试分析标题或正文。
- 无效或无法解析的单个目录目标不得导致 PDF 无法阅读；对应项应不可用或安全忽略。

## 页面缩略图

- 页面模式采用 macOS `PDFThumbnailView`，通过单列上限呈现纵向缩略图，并显示 PDFKit 提供的页码标签。
- 缩略图视图绑定阅读区正在使用的同一个 `PDFView`，由 PDFKit 同步当前页和点击跳转，不创建第二套阅读状态。
- 使用 PDFKit 内部的缩略图生成和缓存能力，不在打开文献时自行同步预渲染全部页面，也不建立长期页面图片缓存。
- 当前阅读页在缩略图列表中具有明确的系统选中状态。
- 阅读区滚动、翻页、页码输入、搜索或其他跳转改变当前页时，缩略图选择自动跟随，并在必要时滚动到可见区域。
- 点击缩略图跳转到对应页面。
- 切换论文时缩略图立即切换到新文档，不能短暂显示或操作旧论文页面。
- 长 PDF 的缩略图加载不得阻塞主阅读区滚动和翻译。

P3 不提供缩略图大小调节、多列网格、拖动重排、页面删除、旋转、提取或导出。

## 阅读状态

### 状态模型

每篇论文具有一个明确状态：

```text
未读 → 阅读中 → 已读完 → 未读
```

- 新导入论文默认“未读”。
- 从旧版文献库迁移的现有论文统一默认为“未读”。
- 打开、翻页、翻译、搜索或添加高亮都不会自动改变阅读状态。
- 状态在应用重启、文件同卷移动、重命名和成功重新定位后保留。

### 行内操作

论文行右侧显示一个紧凑的状态按钮，建议使用以下系统图标语义：

- 未读：空心圆；
- 阅读中：半填充圆；
- 已读完：带勾实心圆。

点击按钮只切换状态，不选择、打开或关闭论文：

- 未读时点击进入阅读中；
- 阅读中时点击进入已读完；
- 已读完时点击回到未读。

按钮提供当前状态的 tooltip 和完整辅助功能说明，例如“未读，点击标记为阅读中”。不能只依赖颜色表达状态。

论文右键菜单同时提供“标记为未读”“标记为阅读中”“标记为已读完”，当前状态显示勾选或不可重复执行，便于直接指定而不必循环点击。

## 筛选、搜索与排序

### 文献模式布局

文献模式顶部按以下层级组织：

```text
[全部 ▾]  [最近打开 ▾]
[搜索标题、作者或文件名]  ＋
```

- 状态筛选包含“全部 / 未读 / 阅读中 / 已读完”。
- 搜索只作用于当前状态筛选结果，继续匹配标题、作者和原始文件名。
- 启动时状态筛选恢复为“全部”，搜索词恢复为空，避免论文被意外隐藏。
- 如果论文在某个状态筛选下被改为其他状态，它立即从当前列表消失。
- 即使当前打开的论文因筛选或搜索而从列表消失，PDF、阅读位置、译文和高亮仍保持不变。

### 排序

支持四种排序方式：

- 最近打开：默认选项，按 `lastOpenedAt` 从新到旧；`lastOpenedAt` 为空的论文排在其后，并按导入时间从新到旧。当前导入流程会立即打开新论文，因此成功导入也计作一次最近打开。
- 添加时间：按导入时间从新到旧。
- 标题：使用本地化、不区分大小写的标题升序；相同标题以导入时间和稳定 ID 保证顺序稳定。
- 年份：有年份的论文从新到旧，无年份论文排在最后；同年份再按标题排序。

用户选择的排序方式持久化，下次启动继续使用。排序方式属于应用偏好，不写入每一条论文记录。

打开论文后更新其最近打开时间；在“最近打开”排序下列表可以立即重新排序，但当前论文必须继续保持选中。

## 数据模型与迁移

- 文献库 schema 从当前版本升级，为 `PaperRecord` 增加可编码的阅读状态字段。
- 状态使用稳定的字符串值保存，不依赖图标名或本地化显示文案。
- 旧 schema 迁移时逐条保留现有 ID、书签、文件身份、元数据、阅读页码和时间字段，并把阅读状态补为未读。
- 迁移结果必须先成功原子落盘，之后才能允许状态编辑；迁移失败继续进入现有文献库只读保护，绝不覆盖旧文件。
- 排序偏好使用现有设置体系持久化；筛选、搜索词和左侧栏模式只保存在当前界面状态中。
- 目录展开状态、目录选择和缩略图选择不跨应用重启保存。
- P3 不新增独立的目录或缩略图数据文件，也不缓存可长期失效的 PDF 页面图片。

## 异常与性能边界

- 目录缺失或个别目录目标无效时，PDF 阅读、搜索、翻译和高亮继续可用。
- 缩略图尚未生成时显示占位状态，不能用同步等待阻塞主线程。
- PDF 被移动、重命名或重新定位后，目录和缩略图从当前解析出的 PDFDocument 重新建立。
- 文件不可用、损坏或受密码保护时，目录和页面模式沿用阅读区现有错误边界，不尝试单独绕过。
- 数百页 PDF 的缩略图列表必须保持可滚动；依赖 `PDFThumbnailView` 的内部按需生成和缓存，不自行预渲染整份文档。验收以阅读区响应和实测内存为准。
- 文献筛选和排序在典型的小型本地库中应即时完成，不为 P3 引入数据库或后台索引服务。

## 不纳入 P3

- 返回上一位置、前往下一位置或跨论文导航历史
- 自动生成目录、正文标题识别和 OCR 目录
- 缩略图网格、大小调节、拖动重排和页面编辑
- 收藏、星标、任意标签、文件夹、项目和集合
- 智能集合、保存的搜索和跨文献全文搜索
- 自动推断阅读状态或按阅读进度自动完成
- 高亮笔记、评论、导出和跨文献高亮汇总
- 多窗口、标签页、云同步和协作
- 修改或写回原 PDF

## 验收标准

P3 第一版需要同时满足以下条件：

1. 左侧栏可以在“文献 / 目录 / 页面”之间切换，冷启动默认文献模式，切换不会改变阅读内容。
2. 切换论文时保留当前侧栏模式，并且目录和缩略图只显示新论文内容。
3. 有内置目录的 PDF 按原始层级显示，展开、折叠和文档内点击跳转可用；外部及不支持的动作不会被意外执行。
4. 普通滚动和其他跳转不会自动改变目录选中项；无目录 PDF 显示正确空状态。
5. 页面模式以绑定现有 `PDFView` 的单列 `PDFThumbnailView` 显示纵向缩略图与页码，当前阅读页自动选中并保持可见。
6. 点击缩略图可以跳页，长 PDF 的缩略图加载不阻塞阅读区操作。
7. 新导入和迁移后的论文默认未读，打开论文不会自动改变状态。
8. 行内状态按钮按“未读 → 阅读中 → 已读完 → 未读”循环，且不会误触论文选择或打开。
9. 右键菜单可以直接指定三种阅读状态，状态在重启、移动和重新定位后保留。
10. “全部 / 未读 / 阅读中 / 已读完”筛选准确，状态变化后列表立即更新。
11. 搜索只在当前状态筛选结果中匹配标题、作者和原始文件名；隐藏当前论文时阅读不中断。
12. 最近打开、添加时间、标题和年份四种排序符合定义，默认最近打开，用户选择跨重启保留。
13. 最近打开排序变化后，当前论文仍保持选中，不产生错误打开或丢失阅读状态。
14. 旧文献库迁移保留全部现有 P0–P2 数据；损坏、未来版本和迁移落盘失败仍安全进入只读状态。
15. 现有 PDF 阅读、页码、搜索、翻译、元数据、高亮、删除确认和撤销行为无回归。
16. 原 PDF 文件内容和哈希在目录浏览、缩略图浏览和状态编辑前后保持不变。

## 验收样本与观察项

除现有 P0–P2 样本外，P3 至少使用：

- 一份包含三层以上目录结构和有效目标位置的论文；
- 一份完全没有目录的普通 PDF；
- 一份包含个别无效目录目标的 PDF；
- 一份 300 页以上的长 PDF，用于缩略图滚动和内存观察；
- 一份包含年份和一份缺少年份的文献集合，用于排序；
- 一个从当前文献库 schema 迁移的真实副本。

Release 验收记录目录首次显示耗时、长 PDF 首批缩略图出现时间、快速滚动缩略图时的响应、切换侧栏模式的响应，以及空闲和滚动后的内存变化。P3 先建立可重复基线，不在实现前设定脱离实测的硬性数字。

## P3 完成之后

P3 完成后先观察目录、缩略图和阅读状态是否足以支撑日常论文阅读与回顾。只有当三态状态无法表达真实整理需求时，再讨论收藏、标签或集合；只有当目录和缩略图仍不足以找回阅读位置时，再讨论导航历史。
