# P8 检查点二：嵌套文献集与元数据体验

日期：2026-08-31

结论：**通过。按计划停在检查点二，不进入目录扫描、Zotero 网络/XPC 或复制事务。**

## 本检查点完成内容

- 文献集来源栏改为原生递归展开树。根节点与同级子节点按本地化、不区分大小写
  的名称排序；展开状态按稳定 UUID 保存，已删除和非法 ID 会安全剪除。
- 选中用户文献集后新建默认作为其子集，同时保留明确的“新建顶层文献集”入口。
  新建、重命名、移动、移到顶层和删除都使用同级名称规则和持久化前候选快照验证。
- 文献集可拖到另一用户文献集下，也可通过菜单或拖到“全部文献”移到顶层；
  拖入自身、后代或同级重名目标在修改前拒绝。读只状态不提供可写菜单或接受拖放。
- 父文献集的列表和计数都递归包含全部后代，同一论文有多个后代归属时仍只显示和
  计数一次。“未分类”仍只表示零显式归属。从父来源移出论文会一次移除目标子树中
  的全部归属。
- 删除确认框明确列出递归删除的文献集数和受影响论文数，并说明论文、PDF、高亮、
  笔记和阅读位置不会删除。整个子树、父级、名称与多重归属是一个撤销动作；新建、
  改名、移动和成员变更也都保持完整撤销/重做。
- Return 继续在文献集树中进入改名，Delete 打开递归删除确认；新建、改名失败后
  焦点保留在输入框。树节点、按钮、拖放目标、删除数量和读只状态都有可读的辅助功能标签。
- 详细元数据编辑器分为基本信息、创作者、发表信息、标识符与链接、其他。创作者可
  增删、上下排序、选择已知或保留未知角色，并分别支持个人姓名与机构/literal 名称。
- 编辑器覆盖结构化模型的全部字段，包括附件标签和不暴露路径、Zotero key 或 server ID 的
  只读来源摘要。无效年份、DOI 或非 HTTP(S) URL 不覆盖已保存数据；整份编辑在验证通过
  后一次原子提交，并由 Store 自行计算精确的手动字段标记。
- 普通搜索扩展到唯一标题、文件名、全部创作者、原始日期/年份、容器标题、DOI、
  ISBN、ISSN、arXiv、未知标识符和 URL。摘要、语言、出版社和附件标签不参与普通搜索。
