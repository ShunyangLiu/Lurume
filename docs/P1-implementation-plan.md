# Lurume P1 实现计划

状态：实现与验收完成
更新日期：2026-08-27

## 实现目标

按 [P1 讨论记录](P1-plan.md)中全部“已确认”条目实现：译文优先检查器、启动即显示的翻译面板、论文标题列表、PDF 属性元数据、手动编辑与文献库搜索，以及 v1→v2 文献库无损迁移。

## 对尚待确认项采取的默认选择

以下按文档原则取了最保守的实现，冻结前可随时改：

- 来源信息位置：文献名与页码置于译文上方（标识来源的信息置顶）。
- 检查器显示偏好：每次启动一律显示；会话内隐藏后自动翻译不再弹出，用户明确发起手动翻译时重新显示，重启恢复默认。
- 原文查看入口：暂不提供；复制原文始终可用。
- DOI 字段：不加入。
- 排序与年份分组：未实现。第二行严格限定为“作者 · 年份”，两者都缺失时整行省略。

## 数据层变更

- `PaperRecord` 升级为 schemaVersion 2：新增 `title`、`authors`、`year`、`manuallyEditedFields`、`didReadAutoMetadata`、`originalFileName`；`displayName` 由前两者取代。
- 迁移：v1 快照载入时以 displayName 作为回退标题、以 fallbackPath 的最后路径分量恢复真实文件名，选中项与全部字段保留，并立即落盘为 v2；早期 P1 v2 构建已经写入的无扩展名 originalFileName 也在载入时幂等修复。
- 降级模式：库损坏、版本高于支持或迁移结果无法落盘时禁止导入与一切编辑，并持续呈现只读错误状态，绝不静默清空重建。
- 自动读取一次性原则：导入时后台读取一次（utility 优先级）；存量旧记录在首次成功打开且书签解析成功时补偿一次；文件不可用不消耗机会。
- 判废规则：属性标题为空白或忽略大小写等于文件名（含/不含扩展名）即回退文件名，无其他启发式。
- 手动优先级：`setManualTitle/Authors/Year` 写入标记；补全只填未标记且为空的字段。
- 元数据提取走 PDFKit `documentAttributes`，在脱离主线程的 detached 任务中执行。

## 界面变更

- 检查器重排：来源信息在最上，状态行其后，译文为主体；底部常驻“复制译文 / 复制原文”操作栏；空状态为安静的图标加一句话。
- 检查器由 `isInspectorPresented = true` 起始，主窗口打开即占位，首词选择不再改变布局。
- 文献行：两行标题（tooltip 显示原始文件名）＋单行次要信息；不可用状态保持图标与橙色文案。
- 侧栏顶部搜索框：实时匹配标题、作者、原始文件名，大小写不敏感；空态提示区分“尚未导入”与“无匹配”；过滤不掉正在阅读的内容，清空后选中自动恢复。
- 编辑入口：右键菜单仅对当前选中文献提供“编辑文献信息…”；完整表单保存/取消明确提交，只对发生变化的字段写手动标记；`Return` 进入行内改名，再次 `Return` 提交、`Escape` 或点击他处取消。
- 年份为空代表未设置；非整数输入显示就地错误并禁止保存，不会被误当作清空。
- 无界面的窗口级键盘事件监听实现 `⌘F`（打开当前 PDF 搜索）、`⌥⌘F`（聚焦文献库搜索）与全局 `Return`（进入改名），不参与绘制或鼠标命中；改名在存在文本编辑上下文时自动禁用。
- PDF 搜索不再常驻工具栏；`⌘F` 唤醒阅读区右上角浮窗，输入后自动搜索并显示“当前项 / 总数”，当前项使用系统蓝色选区、其他结果使用黄色高亮；`Return` 与 `Shift + Return` 循环跳转并将当前项滚动到阅读区中央，`Escape` 关闭并清除高亮，程序化选区不进入翻译流程。
- 真实论文验证后将原文语言默认值改为英语，目标语言继续默认为简体中文；设置中可切换回自动识别，避免双栏 PDF 的交错页面文本造成错误语言判断。

## 验证结果（2026-08-27）

- Debug 构建与 Release 双架构构建均通过；
- 单元测试 47 项全绿：覆盖判废规则、手动优先级、真实 PDFKit 属性提取（程序化生成的合法 xref 样本）、PDF 搜索结果循环导航、存储层导入补全、迁移与早期 v2 数据修复即时落盘、只读降级拒绝写入、年份校验、列表副标题、检查器隐藏状态、默认英译中和自动识别设置持久化；
- 真实数据验证：验收期产生的 8 篇真实 v1 文献库被测试宿主进程升级到 v2——全部篇目、页码、选中项保留，其中一篇在窗口内完成后台读取（样本无属性，正确消耗唯一一次），其余保持待补全；
- Release 应用携带升级后的库正常启动运行，无崩溃报告。

## 人工验证结果

以下项目已在真实 Mac 的 Release 构建中逐一确认通过，完整记录见
[P1 验收记录](P1-acceptance.md)：

1. `⌘F` 打开当前 PDF 右上角搜索浮窗，`⌥⌘F` 聚焦侧栏搜索框。
2. 浏览状态下按 `Return` 进入行内改名；编辑页码框或搜索框时 Return 不误触改名。
3. 行内改名三种退出路径：Return 提交、Escape 取消、点击他处提交。
4. 右键“编辑文献信息…”表单的保存差异提交与取消不动盘。
5. 启动即见检查器；长选区译文首屏可见；“复制原文/译文”可用。
6. 搜索过滤时阅读不断流；清空恢复选中；无匹配空状态出现。
7. 打开一篇旧文献后其标题由 PDF 属性补全（需使用带属性的 PDF）。
8. 拖放导入与右键重新定位流程回归正常。
