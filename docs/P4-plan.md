# Lurume P4 高亮笔记计划

状态：需求已确认，等待实现指令  
更新日期：2026-08-28

## P4 目标

P4 在现有黄色高亮之上增加最小的阅读笔记能力，让用户能够记录“为什么高亮这段内容”，同时保持 PDF 正文、右侧高亮列表和笔记编辑各自清晰。

```text
创建黄色高亮
→ 单击高亮进行选择
→ 通过高亮旁的笔记标志打开浮动卡片
→ 记录一条纯文本笔记
→ 重启后在原位置继续查看和编辑
```

P4 只完成“单条高亮对应一条就地笔记”的纵向链路，不扩展为独立笔记系统、跨文献知识库或完整批注工具箱。

## 已确认的产品边界

- 笔记必须依附于一条 Lurume 黄色高亮，不支持脱离高亮的独立笔记。
- 每条高亮最多保存一条纯文本笔记，不支持 Markdown、富文本、图片、附件或多条讨论。
- 笔记与高亮继续保存在 Lurume 本地数据中，不写入或修改原 PDF。
- 页面中的黄色高亮、虚线选中轮廓和笔记标志具有不同职责：高亮表达标记，虚线表达当前选择，笔记标志负责打开编辑器。
- 单击黄色高亮正文只选择高亮，不显示笔记、不触发翻译，也不滚动 PDF。
- 单击笔记标志才打开浮动笔记卡片。
- 单击右侧高亮列表仍用于导航：对应高亮跳转并居中显示，但不会自动打开笔记。
- 右侧高亮列表不增加固定笔记编辑区；已有笔记只以一个紧凑图标表示。
- 新建高亮后不自动弹出或聚焦笔记卡片，避免打断连续阅读。
- P4 不替换 PDFKit、现有高亮持久化文件或右侧高亮列表的核心组件，只在现有边界上扩展。

## 对 P2 交互的后续调整

P2 的验收标准规定“单击页面高亮不会自动翻译或切换检查器”，并在当时将页面单击保持为无操作。P4 保留“不自动翻译、不切换检查器”的部分，同时对页面单击作出后续调整：

- 单击页面高亮正文会选择对应高亮并显示虚线轮廓；
- 只有单击笔记标志才显示笔记卡片；
- 单击页面空白处会取消高亮选择并关闭笔记卡片；
- P2 历史计划保持原样，本节作为后续阶段的明确覆盖裁决。

## 页面高亮选择

### 选择行为

- 单击任一黄色高亮片段后，将其对应的整条逻辑高亮设为当前高亮。“单击”在鼠标释放且未发生拖动时才成立：按下时记录命中点，若用户拖动划选文字则交还 PDFKit 的常规文字选择流程，以此同时满足本节选择语义与 P2“高亮不得阻止重新选择包含它的文字”的约束。
- 页面位置保持不变，不调用居中或自动滚动。
- 当前高亮在所有可见片段外显示细虚线轮廓；多行高亮逐行描边，不使用覆盖栏间空白的大矩形。
- 虚线轮廓是临时界面元素，不改变黄色高亮颜色、透明度或持久化坐标。
- 同一时间只有一条当前高亮。选择另一条高亮时，旧轮廓立即移除并显示新轮廓。
- 单击 PDF 页面空白处、切换论文或删除当前高亮时取消选择。
- 普通文字选择、搜索结果高亮和黄色持久高亮必须继续可区分；选择黄色高亮不得制造 PDFKit 蓝色文字选区。

### 与翻译的关系

- 单击黄色高亮正文或笔记标志都不创建翻译选区，不触发自动翻译，也不覆盖最后一次译文。
- 用户重新拖动选择高亮文字时，仍按当前翻译设置处理该文字选区。
- 翻译检查器与高亮检查器的当前模式不因页面高亮选择或笔记编辑而自动切换。

## 页面笔记标志

### 显示规则

- 已有非空笔记的高亮始终显示一个小型笔记标志。
- 没有笔记的高亮平时不显示标志；高亮被选中或鼠标悬停时，临时显示低视觉权重的“添加笔记”标志。
- 点击临时标志打开空白笔记卡片。保存有效内容后，标志变为常驻的“已有笔记”状态。
- 清空笔记后，常驻标志消失；若高亮仍处于选中或悬停状态，则退回临时添加状态。
- 标志不能只依赖颜色区分状态，应同时使用不同的系统图标或图形语义，例如添加状态与已有笔记状态。
- 标志作为 Lurume 的临时界面元素随 PDF 缩放和滚动保持锚定，不创建或写入标准 PDF Note annotation。

### 位置与跨页规则

- 标志锚定在一条逻辑高亮的末尾片段附近，优先位于最后一行高亮末端之外，不覆盖高亮文字。
- 空间不足时可切换到高亮左侧，并限制在当前页面或可用页边区域内。
- 多行高亮只有一个标志，不为每一行重复显示。
- 跨页高亮只有一个标志，锚定在最后一页的最后一个有效片段附近。
- 多个标志位置接近时不得完全重叠；第一版只需要轻量避让，不建立复杂的页边批注轨道。
- 页面旋转、裁切框变化和缩放后重新根据保存的 PDF 页面坐标计算位置，不把屏幕坐标写入持久化数据。

## 浮动笔记卡片

### 打开与关闭

- 单击页面笔记标志后，在标志附近打开一个带方向指示的原生浮动卡片。
- 同一时间最多打开一张笔记卡片。打开另一条笔记时，先保存并关闭当前卡片。
- 单击高亮正文只改变选择，不打开卡片。
- 单击右侧高亮列表只导航和选择，不打开卡片。
- 点击卡片和对应标志之外的界面、按 `Escape`、切换论文或删除当前高亮时，保存当前编辑并关闭卡片。
- 当前页变化、缩放或滚动位置累计移动超过一个视口高度时，视为明显滚动，立即保存并关闭卡片，避免卡片与锚点视觉脱节；高亮选择是否保留由触发操作决定。
- 卡片优先显示在不会遮挡高亮正文的一侧，并根据窗口和页面可用空间自动调整方向。

### 编辑行为

- 卡片包含简洁的“笔记”标识和一个纯文本多行编辑区，不重复展示整段高亮原文。
- 没有笔记时显示轻量占位文案；打开已有笔记时直接显示可编辑内容。
- 不设置显式“保存”按钮。输入停止约 500 毫秒后防抖保存，关闭卡片、切换高亮或切换论文前立即刷新待保存内容。
- 笔记没有人为设置的短字符上限；卡片高度增长到合理上限后，编辑区内部滚动，不撑开主窗口布局。
- 只包含空格或换行的内容视为空笔记；非空笔记保留用户输入的正文与换行。
- 文本编辑期间使用原生文本编辑撤销；防抖保存不注册为应用级高亮操作，也不污染现有高亮添加与删除的撤销历史。
- 笔记保存、失败提示和卡片动画不得阻塞 PDF 滚动、搜索或翻译。

## 右侧高亮列表

- 高亮列表继续只显示当前论文，并保持按页码和页面位置排序。
- 每项继续显示页码与最多两行高亮原文预览。
- 已有非空笔记的条目额外显示一个紧凑笔记图标；没有笔记的条目不显示占位图标。
- 列表图标仅表达状态，不成为独立按钮，也不展开笔记正文。
- 点击列表项后，PDF 跳转并将对应高亮居中显示，同时显示虚线选中轮廓。
- 跨页高亮从列表跳转时，以带有笔记标志的最后一个有效片段作为居中目标；没有笔记时仍以逻辑高亮的末尾有效片段作为目标。
- 列表导航不会打开浮动卡片；用户需要在页面中点击笔记标志才能查看或编辑笔记。
- 删除列表项时，附属笔记与高亮作为同一条记录一起删除。

## 数据模型与迁移

- 高亮存储 schema 从版本 1 升级到版本 2。
- `HighlightRecord` 增加可选纯文本笔记和可选的最近修改时间；空笔记不作为有效笔记持久化。
- 一条笔记与高亮使用同一个稳定高亮 ID，不建立容易失配的独立笔记文件或第二套坐标记录。
- 版本 1 数据在全部记录可安全解码后迁移为版本 2，现有高亮的笔记字段为空，原有 ID、论文归属、原文、创建时间和全部页面矩形保持不变。
- 迁移结果必须先成功原子写入，之后才能发布到界面；迁移失败不得覆盖版本 1 文件。
- 顶层损坏、未来版本或包含无法安全解码记录的文件继续沿用 P2 的只读保护，不因 P4 自动清空或重建。
- 文件同卷移动、重命名和成功重新定位不会改变论文稳定 ID，因此笔记继续跟随原高亮。
- 移除一篇论文时，其高亮和附属笔记沿用现有协调删除与失败回退流程，原 PDF 不受影响。

## 保存、撤销与失败回退

- 笔记写入复用高亮存储的原子快照机制，不另外创建频繁失配的 sidecar 文件。
- 每次保存先生成包含旧高亮与新笔记的完整候选快照；落盘成功后才发布新状态。
- 保存失败时保留上一份已成功持久化的快照，卡片显示明确的非阻塞错误，并在当前运行期间保留尚未保存的编辑草稿以便重试或复制。
- 高亮存储处于只读保护时，已有笔记可查看和复制，但编辑、添加笔记、清空笔记和删除高亮均不可用。
- 删除含笔记的高亮时，现有 `⌘Z` 撤销必须同时恢复高亮、笔记和常驻标志；重做再次一起删除。
- 笔记卡片关闭后不提供笔记版本历史或整次编辑回退；P4 只保证编辑器打开期间的原生文本撤销。
- 笔记保存失败不能阻塞阅读、搜索、翻译、目录、缩略图或文献整理。

## 技术边界

- 继续使用当前 `HighlightPDFView` 负责高亮命中与页面交互，不为 P4 替换 PDF 阅读核心组件。
- 黄色高亮仍由内存 `PDFAnnotation` 显示。虚线轮廓和笔记标志默认同样使用临时内存注解：轮廓用 `.square` 类型加虚线 `PDFBorder` 逐行绘制，标志用 `.text` 或 `.freeText` 注解承载，点击通过现有 `PDFView` 注解点击代理处理。注解由 PDFKit 自动跟随缩放和滚动，不引入屏幕坐标换算代码。
- 仅当注解方案无法满足经过确认的具体视觉需求时，才改用独立页面覆盖层绘制。覆盖层以 `HighlightRecord` 的 PDF 页面坐标为唯一锚定来源，必须监听文档视图的布局与滚动变化并即时换算视图坐标，且需在动量滚动下验证轮廓与标志不漂移。从注解切换到覆盖层前，先在本节记录注解做不到的具体原因。
- 两种方案都不得写入原 PDF 或混入其自带批注。
- 浮动卡片使用原生 macOS 弹出界面并锚定到笔记标志（注解方案下由注解边界换算窗口锚点）；不以固定检查器面板或新的应用窗口代替。
- 页面命中优先级必须明确：笔记标志优先于黄色高亮，高亮优先于页面空白；标志的可点击区域可以略大于可见图标，但不得明显遮挡正文选择。
- 注解与覆盖层都不得拦截无关的 PDF 文字选择、链接点击、滚动、缩放或右键菜单。
- P4 不解析或导入原 PDF 已有的 Note、Text 或其他批注，也不把 Lurume 笔记导出为 PDF 批注。

## 键盘与可访问性

- 笔记标志提供“添加高亮笔记”或“打开高亮笔记”的辅助功能标签，并说明所属页码。
- 已选高亮不能只通过虚线或颜色表达；页面辅助功能与右侧列表需要暴露当前选中状态。
- 笔记卡片打开后，键盘焦点进入文本编辑区；`Escape` 保存并关闭，`Tab` 遵循原生焦点顺序。
- 编辑区支持系统复制、粘贴、全选和文本撤销快捷键。
- 右侧列表继续支持键盘选择和 `Delete` 删除；列表选择只导航，不隐式把焦点夺到笔记编辑器。
- P4 第一版不新增全局“添加笔记”快捷键，先验证页面标志交互频率。

## 不纳入 P4

- 独立笔记、论文级笔记、章节总结和跨文献笔记
- Markdown、富文本、代码块、公式、图片、附件和链接预览
- 多条评论、作者身份、回复、共享和协作
- 标签、文件夹、项目、集合、智能集合和保存的搜索
- 跨文献高亮或笔记汇总、全文搜索和知识图谱
- 笔记导出、Markdown 摘录、BibTeX、RIS、CSL-JSON 和写作引用插件
- 笔记版本历史，以及卡片关闭后的整次笔记编辑撤销
- 多种高亮颜色、下划线、删除线、自由绘图和手写批注
- 写回原 PDF、导入原 PDF 批注或导出带嵌入批注的 PDF
- 云同步、账户、多窗口、标签页、iPadOS 和 iOS

## 验收标准

P4 第一版需要同时满足以下条件：

1. 单击页面黄色高亮只选择高亮并显示逐行虚线轮廓，不滚动、不打开笔记、不触发翻译，也不产生蓝色文字选区。
2. 单击页面空白处取消高亮选择并关闭浮动卡片；最后一次译文和检查器模式保持不变。
3. 没有笔记的高亮只在选中或悬停时显示临时添加标志；点击后可以打开空白笔记卡片。
4. 保存非空笔记后，页面旁出现常驻笔记标志，右侧列表出现笔记图标；清空笔记后两处标志按规则消失。
5. 只有点击页面笔记标志才打开浮动卡片；点击高亮正文或右侧列表不会打开卡片。
6. 卡片在高亮附近选择合适方向显示，不遮挡对应正文；同一时间最多存在一张卡片。
7. 笔记按约 500 毫秒防抖自动保存，关闭卡片、切换高亮、切换论文和关闭窗口时刷新待保存内容。
8. 关闭并重新启动应用后，笔记内容、常驻标志和右侧列表图标仍与对应高亮一致，原 PDF 内容和哈希不变。
9. 点击右侧列表项后，对应高亮居中显示并获得虚线轮廓，但笔记卡片保持关闭。
10. 多行高亮逐行描边且只有一个笔记标志；跨页高亮只有一个标志，并锚定在最后一个有效片段附近。
11. PDF 滚动、缩放、跳页、切换论文和窗口尺寸变化后，常驻标志不会漂离高亮；打开的卡片按规则保存并关闭或安全重定位。
12. 删除含笔记的高亮会同时删除笔记与标志，`⌘Z` 和 `⇧⌘Z` 能够成组恢复或再次删除。
13. 笔记编辑器打开期间的原生文本撤销可用，防抖保存不向高亮撤销历史加入大量无意义步骤。
14. 版本 1 高亮数据可以无损迁移到版本 2；迁移失败、未来版本、记录损坏和写入失败不会覆盖原数据。
15. 只读状态下已有笔记仍可查看和复制，任何不可保存的编辑入口明确禁用或给出准确错误。
16. 笔记标志、卡片和虚线轮廓不会阻断普通文字选择、链接、搜索、翻译、目录、缩略图和 PDF 滚动缩放。
17. 现有 P0–P3 自动化测试继续通过，并新增覆盖 schema 迁移、笔记往返、空笔记归一化、保存失败回退、删除撤销、跨页锚点和选择状态的测试。

## 验收样本与观察项

除 P0–P3 固定样本外，P4 至少使用：

- 一份双栏论文，验证逐行虚线不覆盖栏间空白、标志不遮挡相邻栏文字；
- 一份具有大量相邻高亮的论文，验证标志轻量避让和页面可读性；
- 一份跨页高亮样本，验证单一标志、列表居中目标和笔记归属；
- 一份包含页面旋转或不同裁切框的 PDF，验证坐标转换；
- 一份包含数百条高亮、其中至少一百条带笔记的压力样本。

Release 验收记录打开含大量笔记文献的首屏耗时、滚动时轮廓与标志的跟随响应、缩放后的标志稳定性、连续编辑与自动保存响应，以及空闲和长时间阅读后的内存变化。测量继续采用 P0 规定的固定硬件、固定样本与三次中位数方法。同一轮验收顺带补记 P2 遗留的数百条高亮基线与 P3 的缩略图滚动响应，三份数据一次测齐。

## P4 完成之后

P4 完成后先通过真实论文验证“高亮旁的单条短笔记”是否足以表达阅读思考。只有当用户持续需要脱离具体高亮记录章节观点时，再讨论论文级或独立笔记；只有当单篇高亮列表不足以找回已有笔记时，再讨论跨文献汇总、搜索或导出。引用管理、联网元数据和集合整理作为独立后续方向评估，不与 P4 第一版捆绑。
