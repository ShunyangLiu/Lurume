# v0.0.8 数据保护修复

本轮修复 v0.0.7 审查中用临时数据复现的三处问题，不改变数据格式。

## 修复

1. 高亮撤销/重做：删除时按 ID 读取最新记录，以它注册恢复操作，避免创建时的旧值覆盖后来保存的笔记和标记位置。
2. 退出与更新重启：文献库记录最后成功保存的快照，`flushPendingSave()` 返回结果。两个退出入口共用保存检查；失败时默认返回检查，明确选择丢弃后仍须通过笔记草稿保护。无修改或只读文献库不因无法写盘而阻止退出。
3. PDF 重新关联：先持久化候选文献库，再发布新文件引用、清除不可用状态。失败保留原状态，可以重试。

## 验证

- 新增 10 项回归测试，覆盖笔记多次撤销/重做、恢复后再编辑、标题和阅读进度写入失败与重试、只读与未修改文献库退出、重新关联失败与重试、普通退出与更新重启拦截、明确丢弃后继续检查笔记。
- 全量测试：298 项，273 通过，25 项需要模拟服务而跳过，0 失败。
- 本地模拟翻译服务集成测试：20 项全部通过，无跳过；不使用真实 API Key 或文献。
- 发布脚本输入、哈希与路径边界测试通过。
- 正式发布准备流程还会在干净目录重跑全量测试，构建 Intel/Apple Silicon 通用版本并验证 DMG、更新说明和更新源签名。

本次没有在真实磁盘故障下操作用户文献库；写入失败通过测试专用目录模拟。更新重启的取消/继续逻辑有回归测试，但本次没有替换用户当前正在运行的应用做端到端升级试验。
