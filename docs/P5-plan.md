# Lurume P5 文献集与文献库管理计划

状态：需求已确认，等待实现指令  
更新日期：2026-08-28

## P5 目标

P5 在现有扁平文献列表之上增加一个专门的文献库管理模式和 Zotero 风格的文献集，让用户可以按课题、项目或主题组织论文，同时不打断已经稳定的 PDF 阅读流程。

```text
进入文献库模式
→ 在文献集中查找、筛选和多选论文
→ 通过拖放或菜单调整文献集归属
→ 双击论文进入现有阅读模式
→ 重启后恢复上次所在模式和文献集
```

P5 第一版只完成“同窗口文献库模式 + 扁平多重文献集 + 批量归属”的完整链路，不扩展为联网书目数据库、引用管理器或层级知识系统。

## 已确认的产品边界

- 文献集采用 Zotero 风格的多重归属：一篇论文可以同时属于多个文献集。
- 文献集只保存组织关系，不移动、复制、重命名或修改用户的原始 PDF。
- P5 只支持一层扁平文献集，不支持嵌套、标签、智能文献集或保存的搜索。
- “全部文献”和“未分类”是系统固定视图，不是可编辑的用户文献集。
- 删除文献集只删除该文献集及其归属关系，不删除论文、高亮、笔记或原 PDF。
- 文献库管理模式与阅读模式在同一个主窗口内切换，不新增第二窗口或标签页。
- 现有 PDFKit 阅读器、阅读侧栏、翻译检查器、高亮检查器和笔记卡片不因 P5 更换核心组件。
- 文献库模式用于集中管理；阅读模式中的“文献 / 目录 / 页面”侧栏继续服务快速阅读切换，不承担文献集管理。
- P5 不联网抓取 DOI、期刊、摘要或引用信息，也不导入或导出 BibTeX、RIS、CSL-JSON。

## 同窗口模式切换

### 模式模型

主窗口增加两个互斥的应用级模式：

```text
文献库模式 ｜ 阅读模式
```

- 阅读模式保持当前 `NavigationSplitView + PDFView + Inspector` 结构与行为。
- 文献库模式显示文献集来源栏和文献表格，并隐藏翻译/高亮检查器。
- 阅读模式工具栏增加一个使用 `books.vertical` 系统图标的“文献库”入口。
- 从阅读模式点击该入口进入文献库；文献库中双击论文或执行 `⌘O` 后进入阅读模式。
- 如果已有可用的当前论文，从文献库再次点击同一入口可以返回该论文；没有可返回论文时保持文献库模式。
- 切换模式不改变论文阅读状态，不触发翻译，不创建高亮，也不修改原 PDF。
- 从文献库进入阅读时仍由现有安全作用域访问、书签恢复、错误边界和页码恢复流程打开 PDF。
- 返回阅读模式后恢复当前论文最近持久化的页码；P5 不为模式切换额外建立页面历史栈。

### 启动恢复

- 应用保存最后一次可用的主窗口模式。
- 退出时位于文献库，下次启动仍进入文献库；退出时位于阅读模式，下次仍恢复当前论文和页码。
- 应用保存文献库中最后选择的来源，包括“全部文献”“未分类”或某个用户文献集。
- 如果保存的用户文献集已经删除或不可解析，启动时安全回退到“全部文献”。
- 搜索词和阅读状态筛选不跨冷启动保存，始终恢复为空和“全部”。
- 表格排序在冷启动时取设置窗口中的“启动时排序”；同一次运行内切换模式时保留临时排序。
- 阅读侧栏的“文献 / 目录 / 页面”模式继续遵循 P3 的既有规则，不与应用级模式共用持久化字段。

## 文献库界面

### 两栏布局

文献库模式使用原生 macOS 两栏布局：

```text
[来源与文献集] ｜ [搜索、筛选、导入与文献表格]
```

- 左栏使用原生 source list 语义，宽度可由用户拖动，并复用主窗口现有的侧栏显示/隐藏能力。
- 右栏以可扩展宽度显示文献表格，不显示 PDF 页面或阅读检查器。
- 窗口从文献库切回阅读时恢复阅读模式原有栏宽；两个模式的栏宽互不覆盖。
- 文献库模式中的空状态保持安静，不用大面积营销插图或重复说明填满窗口。

### 左侧来源栏

左栏按以下顺序显示：

```text
资料库
  全部文献       120
  未分类          18

文献集               ＋
  毕业论文         42
  迁移学习         16
```

- “全部文献”显示所有论文；“未分类”显示不属于任何用户文献集的论文。
- 系统固定视图不可重命名、删除或作为拖放目标。
- 用户文献集按本地化、不区分大小写的名称升序排列；同名比较结果相同时用创建时间和稳定 ID 保证顺序稳定。
- 每项右侧以低视觉权重显示总论文数；计数不受当前搜索词或阅读状态筛选影响。
- “文献集”标题旁的 `+` 创建文献集；来源栏空白处右键也提供“新建文献集”。
- 选中文献集后按 Return 或使用右键菜单进入原生行内改名；焦点位于文献表格时，Return 仍按 P1 规则编辑论文元数据。
- 文献集名称去除首尾空白后必须非空，并在当前扁平层级中按本地化、不区分大小写比较保持唯一。
- `Escape` 取消尚未确认的新建或改名；名称无效时保持编辑并给出准确的行内提示。
- 删除文献集前显示明确确认，说明论文及其高亮、笔记不会被删除。

### 文献表格

右侧使用标准 macOS `Table` 或等价原生表格，第一版固定为四列：

- 阅读状态：窄图标列，沿用 P3 的未读、阅读中、已读完图标和循环规则；
- 标题：主列，占据剩余宽度，并保持论文标题为最主要信息；
- 作者：显示当前元数据作者；
- 年份：显示四位年份，缺失时保持为空。

第一版不增加文件名、路径、添加时间、最近打开时间或文献集标签列；这些字段仍可参与搜索或排序，但不挤压标题。

- 单击行只选择，不打开论文。
- `⌘` 单击、Shift 单击和原生键盘范围选择支持多选。
- 点击状态图标只更新该行阅读状态，不打开论文；状态图标提供完整辅助功能说明。
- 仅选择一篇论文时，Return 沿用 P1 的元数据编辑入口；多选时 Return 不打开论文也不批量覆盖元数据。
- 双击一篇论文或在仅选中一篇时执行 `⌘O`，进入阅读模式并打开该论文。
- 文件不可用的论文继续显示现有警告语义；尝试打开时沿用重新定位流程。
- 表格选中项因筛选、搜索、移出当前文献集或删除而消失时，不能误把操作落到自动补位的下一行。
- 切换来源、筛选或排序只改变表格内容，不改变已经打开论文的页码、译文、高亮或笔记。

## 搜索、筛选与排序

- 文献库右栏提供现有标题、作者和原始文件名搜索；搜索只作用于当前来源。
- 阅读状态筛选继续包含“全部 / 未读 / 阅读中 / 已读完”，并只作用于当前来源。
- 搜索和阅读状态筛选组合使用，顺序语义为“当前来源 → 阅读状态 → 搜索”。
- “未分类”是文献集归属来源，不与“未读”阅读状态混用；图标、名称和辅助功能必须明确区分。
- 表格支持最近打开、添加时间、标题和年份四种现有排序。
- 点击表头或排序菜单只改变当前运行期间的排序，不改写设置中的启动默认值。
- 冷启动从设置中的“启动时排序”初始化；默认值继续是 P3 后续裁决确定的“添加时间”。
- 最近打开排序下打开论文可以立即改变行顺序，但选中论文和即将执行的打开动作必须保持稳定。
- 左侧来源计数始终是未应用临时搜索和状态筛选的总数，避免计数随输入抖动。

## 文献集操作

### 单篇与批量归属

- 将一个或多个已选论文行拖到用户文献集，只执行“加入”，不会切换或移除其他归属。
- 已经属于目标文献集的论文保持不变，不创建重复成员关系。
- 文献右键菜单提供“加入文献集”子菜单，列出全部用户文献集。
- 单选时，论文已经所属的文献集显示勾选；点击项目切换该归属。
- 多选时，全部所选论文都属于某文献集则显示勾选，只有部分属于则显示原生混合状态，全部不属于则不勾选。
- 点击未选或混合项目，将全部所选论文加入；点击已勾选项目，将全部所选论文移出。
- 在某个用户文献集内，右键菜单额外提供“从「文献集名称」移除”，只移除当前归属。
- 一次批量归属变更作为一个撤销步骤；`⌘Z` 和 `⇧⌘Z` 成组恢复或重做全部成员关系。
- 归属变更不改变论文添加时间、最近打开时间、阅读状态、元数据、页码、高亮或笔记。

### 删除快捷键

- 焦点位于用户文献集的表格时，`⌘Delete` 只把所选论文从当前文献集移除。
- 焦点位于“全部文献”或“未分类”时，`⌘Delete` 沿用现有“从文献库移除…”确认流程。
- 从文献库移除论文继续协调删除其 Lurume 高亮与笔记记录，但绝不删除原始 PDF 文件。
- 普通 Delete 不作为文献库级删除快捷键，避免与高亮列表和文本编辑器的既有行为冲突。
- 只读保护状态下所有归属、改名、删除和批量操作禁用，但已有来源与成员关系仍可浏览。

## 导入与当前文献集

- 当前选中用户文献集时，通过 `+`、应用菜单、拖入 PDF 或文件选择器导入的新论文自动加入当前文献集。
- 当前位于“全部文献”或“未分类”时，导入论文不加入任何用户文献集，因此出现在“未分类”。
- 一次导入多个 PDF 时，对全部文件应用导入开始时的同一个目标文献集，避免导入过程中切换来源造成部分归属变化。
- 若导入文件与文献库中的现有记录按 P0 文件身份规则判定为同一文件，不创建重复论文记录。
- 重复导入发生在用户文献集内时，把已有论文加入当前文献集；发生在固定视图时保持其既有归属不变。
- 重复导入仍不进行内容哈希查重，跨卷复制的独立文件继续按 P0 规则处理。
- 从 Finder 把 PDF 直接拖到某个用户文献集时，新文件导入并加入该文献集；拖到固定视图或表格空白处时按当前来源规则处理。
- 导入、判重和文献集归属作为一个协调事务：保存失败时不得出现论文已导入但归属只在内存中存在的半完成状态。

## 数据模型与迁移

- 文献库 schema 从版本 3 升级到版本 4；高亮 schema 2 不因 P5 改动。
- 新增 `CollectionRecord`，至少包含稳定 UUID、名称和创建时间。
- 每篇 `PaperRecord` 保存去重后的文献集 UUID 集合；序列化时使用稳定顺序的数组，运行时按集合语义处理。
- `LibrarySnapshot` 继续作为论文、文献集和成员关系的单一原子快照，不新增容易失配的第二个文献集 sidecar 文件。
- “全部文献”和“未分类”由查询规则计算，不写成普通 `CollectionRecord`，避免被误改或误删。
- 版本 1、2、3 文献库迁移到版本 4 时，保留全部论文 ID、书签、文件身份、元数据、页码、阅读状态和时间字段；文献集列表与全部成员关系初始化为空，因此旧论文自然出现在“未分类”。
- 迁移必须先完整解码、验证引用并原子写入版本 4 快照，成功后才能发布可编辑状态；失败不得覆盖旧文件。
- 重复文献集 ID、重复规范化名称、论文引用不存在的文献集或其他无法安全解释的关系视为数据不一致，进入现有只读保护并给出可诊断错误，不静默删除用户组织数据。
- 删除文献集时，在同一个候选快照中删除记录及所有论文中的对应成员 ID；快照落盘成功后才更新界面。
- 从文献库移除论文时，其成员关系随论文记录一起消失；现有高亮协调删除和失败回退流程保持不变。
- 最后模式和最后来源使用轻量偏好保存，不写入每一篇论文；无效模式值或来源 ID 安全回退。

## 保存、撤销与失败回退

- 创建、改名、删除文献集以及加入、移出、批量归属继续使用文献库现有原子保存边界。
- 每次操作先生成完整候选快照，落盘成功后才发布到 `LibraryStore`；失败时界面与上一份成功快照保持一致。
- 单次拖放、一次子菜单批量切换或一次“从当前文献集移除”各注册为一个应用级撤销动作。
- 撤销和重做必须重新经过持久化；写入失败时保留当前已持久化状态并显示非阻塞错误。
- 删除文献集需要确认；第一版不要求删除确认后的跨启动“废纸篓”，但同一运行期间允许通过撤销恢复文献集及其完整成员关系。
- 文献库处于只读保护时，允许搜索、筛选、排序、选择和打开论文；所有会写入快照的控件明确禁用。
- 文献集保存失败不得阻塞现有 PDF 阅读、翻译、搜索、高亮、笔记、目录或缩略图。

## 与现有阶段的兼容裁决

- P1 的“右键或 Return 编辑标题、作者和年份”继续有效；P5 只在来源栏焦点位于用户文献集时把 Return 用于文献集改名。
- P3 的三态阅读状态、四种排序和“设置只控制下次启动默认排序”继续有效，并扩展到文献库表格。
- P3 阅读侧栏继续保留现有快速文献列表，不在其中嵌入文献集树或第二套多选管理界面。
- P4 高亮和笔记按稳定论文 ID 归属；文献加入、移出或删除文献集不会改变论文 ID，因此不影响高亮与笔记。
- 从整个文献库移除论文仍使用现有确认、撤销和高亮协调删除流程；P5 不把“从文献集移除”误写成“从文献库移除”。
- P5 不改变 PDF 右键菜单、翻译语言设置、自动翻译设置或高亮快捷键。

## 键盘与可访问性

- 文献库入口、来源项、文献集计数、表头、状态图标和归属菜单提供准确的简体中文辅助功能标签。
- 固定来源除名称外还应暴露语义，例如“未分类，18 篇文献”，不能只依赖图标。
- 选中文献集和选中论文使用原生选择状态，不只依赖颜色。
- Return 的行为由当前焦点明确决定：来源栏改名文献集，单篇表格选择编辑元数据，文本编辑器内输入换行或确认原生编辑。
- `⌘O` 只在表格恰好选择一篇可打开论文时可用；多选或无选中时禁用并提供正确菜单状态。
- `⌘Delete` 按当前来源执行“移出文献集”或“从文献库移除”，确认文案必须包含准确对象和影响范围。
- 拖放不是唯一的成员管理入口；键盘和辅助技术用户可以通过“加入文献集”菜单完成相同操作。
- 多选批量菜单的开、关和混合状态必须向辅助功能暴露，不能只靠勾号视觉表达。

## 性能与技术边界

- 文献库模式优先使用 SwiftUI 与 AppKit 原生列表、表格、拖放和菜单能力，不引入运行时第三方依赖。
- P5 继续使用本地 JSON 快照，不为第一版引入 SwiftData、Core Data、SQLite、后台数据库服务或全文索引。
- 来源筛选、搜索、排序和计数在内存中的文献记录上完成；不得为每一行同步解析 PDF 或重新解析安全作用域书签。
- 文献集成员关系使用稳定 UUID，不使用名称作为外键；改名不得遍历重写与名称相关的成员数据。
- 批量操作构造并保存一次候选快照，不为每篇论文分别写盘或发布大量中间界面状态。
- 表格只渲染可见行，状态图标和计数变化不得导致整窗闪烁、选区丢失或阅读状态按钮延迟。
- 模式切换可以按现有持久页码安全重建 PDF 阅读视图；P5 不要求为了零重载而在文献库后台长期保留整份 PDF 渲染树。
- 原 PDF 在文献集创建、归属、改名、删除、排序和模式切换前后必须保持字节不变。

## 不纳入 P5

- 嵌套文献集、手动文献集排序和自定义图标或颜色
- 任意标签、星标、智能文献集、保存的搜索和规则自动归类
- 文献集内手动论文排序、看板、时间线和项目任务管理
- 联网 DOI、Crossref、arXiv、期刊、摘要、封面或引用次数补全
- BibTeX、RIS、CSL-JSON、EndNote、Zotero 数据导入导出和写作引用插件
- 跨文献全文搜索、高亮/笔记聚合、知识图谱和语义检索
- 监控文件夹、自动导入、内容哈希查重和重复文献合并
- 修改、移动、复制、重命名或写回原 PDF
- 云同步、账户、共享文献库、协作、冲突合并和权限管理
- 多窗口、标签页、iPadOS 和 iOS

## 验收标准

P5 第一版需要同时满足以下条件：

1. 主窗口可以在文献库模式与阅读模式之间切换；文献库不显示翻译/高亮检查器，阅读模式布局无回归。
2. 冷启动恢复上次有效模式和来源；已删除或无效的来源安全回退到“全部文献”，搜索与状态筛选恢复默认。
3. 左栏固定显示“全部文献”和“未分类”，两者计数准确且不可改名、删除或接收内部成员拖放。
4. 可以创建、行内改名和删除扁平用户文献集；名称校验、排序、确认和空状态符合计划。
5. 删除文献集不会删除论文、高亮、笔记或原 PDF；撤销可以恢复文献集及其成员关系。
6. 文献表格只显示状态、标题、作者和年份四列，标题为主列；单击、多选、状态切换和文件不可用提示正确。
7. Return 在单选论文时编辑元数据，双击或 `⌘O` 打开论文；多选时不会误开或批量覆盖元数据。
8. 搜索、阅读状态筛选和四种排序只作用于当前来源；左侧总数不随临时搜索或筛选抖动。
9. 一篇论文可以同时属于多个文献集，加入一个文献集不会从其他文献集移除，也不会创建重复成员关系。
10. 单选与多选的“加入文献集”子菜单准确显示关闭、勾选和混合状态，并按约定执行批量加入或移出。
11. 将单篇或多篇论文拖到用户文献集只执行加入；拖到固定来源不会产生错误成员关系。
12. 用户文献集中的 `⌘Delete` 只从当前文献集移除；“全部文献”和“未分类”中的 `⌘Delete` 才进入整库移除确认。
13. 当前位于用户文献集时导入的新 PDF 自动归入该集；固定来源导入的新论文保持未分类。
14. 重复导入不创建第二条论文记录；在用户文献集内重复导入时，已有论文正确加入当前文献集。
15. 一次批量归属或移出可以成组撤销和重做，不改变论文元数据、状态、页码、高亮或笔记。
16. 版本 1、2、3 文献库可以无损迁移到版本 4，全部旧论文迁移后出现在“未分类”。
17. 未来版本、损坏数据、无效成员引用和迁移或写入失败不会覆盖旧快照，并进入准确的只读保护。
18. 文献集操作、模式切换和打开论文前后，原 PDF 内容与哈希保持不变。
19. 数百至上千篇论文和多文献集下，来源切换、搜索、排序、多选与拖放不阻塞主线程或造成明显列表闪烁。
20. 现有 P0–P4 自动化测试继续通过，并新增覆盖 schema 迁移、成员关系、多选混合状态、导入目标、重复导入、撤销、删除文献集和模式恢复的测试。

## 验收样本与观察项

除 P0–P4 固定样本外，P5 至少使用：

- 一个从真实版本 3 文献库复制得到的迁移样本；
- 至少三个用户文献集，其中一篇论文同时属于两个以上文献集；
- 一组包含未分类、缺失文件、缺少作者和缺少年份记录的混合文献；
- 一次至少 50 篇论文的多文件导入与归属测试；
- 一次至少 200 篇已选论文的批量加入、移出、撤销和重做测试；
- 一个约 1,000 篇论文、100 个扁平文献集的生成快照，用于来源切换、计数、搜索和排序观察；
- 一个包含重复 ID、重复规范化名称、未知成员引用和未来 schema 的故障快照集合。

Release 验收记录冷启动进入文献库的耗时、首次表格显示时间、来源切换与搜索响应、批量拖放和保存耗时、文献库与阅读模式切换耗时，以及空闲和大列表滚动后的内存变化。测量继续采用 P0 规定的固定硬件、固定样本和三次中位数方法，不在实现前设定脱离实测的硬性数字。

## 实现前检查点

- 先确认现有文献库版本 1–3 迁移测试样本完整，并复制真实用户数据做只读演练。
- 先用最小原生表格原型验证多选、状态按钮、Return 编辑和双击打开不会互相抢事件。
- 先验证 SwiftUI 原生拖放能稳定携带多个论文 UUID，并区分内部论文拖放与 Finder PDF URL。
- 先验证同窗口模式切换不会造成安全作用域访问泄漏、待保存页码丢失或笔记草稿未刷新。
- 如果实现需要替换现有 `NavigationSplitView`、`PDFReaderView`、JSON 快照或其他计划中的核心组件，必须先停止并取得用户确认；不能先改代码再回写本计划。

## P5 完成之后

P5 完成后先通过真实文献库观察扁平多重文献集是否足以支撑课题整理。只有当用户持续需要同一主题下的层级拆分时，再讨论嵌套文献集；只有当文献集不足以表达交叉属性时，再讨论标签。联网元数据补全、引用格式与 BibTeX/RIS 导出作为独立后续阶段评估，不与 P5 第一版捆绑。
