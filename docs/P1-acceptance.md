# Lurume P1 验收记录

状态：通过
验收日期：2026-08-27

## 结论

P1 已确认范围全部实现，并在真实 Mac 的 Release 构建中完成人工交互验收。翻译检查器、
PDF 属性元数据、Finder 式文献信息编辑、文献库搜索、存量库升级以及 P0 文件流程均可用于
日常的小规模论文阅读与管理。

实现审查和验收期间修复了以下问题：

- 损坏、未来版本或迁移后无法保存的文献库现在进入真正的只读状态，导入、编辑、移除和
  重新定位都不会覆盖原数据；
- 非整数年份不再被误当作清空，而是显示就地错误并禁止保存；
- 文献列表第二行严格限定为作者和年份，原始文件名与论文标题分别保存；
- 会话内关闭检查器后，自动翻译不再强制将其打开，手动翻译仍会重新显示；
- v1 迁移和早期 P1 v2 数据会从文件路径修复真实原始文件名；
- 用于 `Return` 的零尺寸 SwiftUI 按钮会在 PDF 中央留下蓝色焦点控件，现已改为不参与
  绘制和鼠标命中的窗口级键盘事件监听。

## 验收后修订：默认英译中

真实阅读 `main.pdf` 第 10 页时，PDFKit 提取的双栏页面文本发生交错，
`NLLanguageRecognizer` 将英文误判为挪威语（约 50%）或丹麦语（约 43%），英语置信度
仅约 2%，最终触发不支持的语言组合错误。根据 Lurume 以英文论文阅读为主的使用场景，
翻译设置调整为：原文语言默认英语、目标语言默认简体中文；用户仍可在设置中将原文语言
切换为“自动识别”。固定英语时不再读取页面语言，因此不会受到双栏文本提取顺序影响。

## 验收后修订：PDF 搜索浮窗

PDF 全文搜索从工具栏常驻输入框改为按需浮窗。阅读文献时按 `⌘F` 在 PDF 右上角打开搜索，
输入后自动查找并显示当前匹配位置；`Return` 前往下一项，`Shift + Return` 前往上一项，
结果到达首尾时循环。`Escape` 或关闭按钮会关闭浮窗并清除高亮。文献库搜索保留在侧栏，
可用 `⌥⌘F` 聚焦。
