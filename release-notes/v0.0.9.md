# Lurume v0.0.9

发布日期：2026-09-05

## 翻译配置更方便

- 内置 OpenAI、Claude、智谱 GLM、OpenRouter、火山引擎和 DeepSeek 的普通 API 地址与常用模型，选择服务商即可快捷填写，地址和模型仍可自由修改。
- 各服务商分别记忆已保存的配置，升级前的地址、模型与提示词保留为“自定义服务”。预设模型是否可用，以服务商账户权限为准；智谱和火山引擎预设不是 Coding Plan 地址。
- 新增 Claude 原生 Messages 接口，支持流式与非流式翻译、取消，以及响应截断提示。
- 低延迟翻译选项对支持的服务关闭深度思考；模型不兼容调优参数时可关闭此选项。
- 保存配置和测试连接按钮固定在设置窗口底部，API Key 支持显示和隐藏。

## API Key 存储变更：旧用户请留意

- 翻译 API Key 改为明文保存在权限受限的本机应用数据文件中，按服务商、协议和地址隔离；启动、打开设置和翻译时不再自动访问钥匙串。
- **升级后，原本使用模型翻译的用户，请先到“设置 → 翻译”点击“从旧版钥匙串读取 Key…”，核对地址后保存配置；也可以直接重新填写 Key。** 主动读取时可能出现一次系统授权，旧钥匙串条目不会自动删除。
- 更换服务商、协议或地址会清空未保存的 Key，并加载目标配置的 Key，避免把上一家的 Key 发给另一家。
- 本地 Key 文件未加密，同一系统用户下的程序、管理员或备份可能访问，请勿分享包含 Key 的应用数据或备份。

## 兼容性

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已安装旧版的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
