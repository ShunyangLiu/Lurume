# Lurume v0.0.7

发布日期：2026-09-05

## 翻译稳定性

- 修复系统翻译取消或切换选区后，旧请求可能再次把界面变为“正在翻译”，并让新请求失去超时保护的问题。
- 模型因输出长度上限或内容过滤停止时，不再把不完整译文标记并缓存为成功；已经收到的内容会保留，并提示重试。
- 修复连续模型翻译时，旧后台连接的迟到回调可能误伤新请求的问题。
- 修复少数兼容服务在流末尾没有空行时，最后一段译文可能丢失的问题。

## 数据保护与 PDF 搜索

- 笔记保存失败时会保留独立的恢复草稿；再次打开笔记时可选择保存恢复内容或保留原笔记。
- 退出或安装更新前会检查未保存草稿；文献库和高亮数据保存时保留上一份有效快照。
- PDF 全文搜索改为可取消的异步搜索，大文档搜索、切换关键词和关闭搜索时更流畅。

## 兼容性

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已安装旧版的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
