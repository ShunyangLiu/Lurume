# Lurume v0.0.16

发布日期：2026-09-09

## 笔记图标修复

- 拖动图标后，如果位置保存失败，界面会恢复到原位置，保持显示与保存结果一致。
- 自动摆放笔记图标时同时寻找上下空位，修复页面顶部附近有空位却仍然重叠的问题。
- 保留用户手动保存的图标位置。

## 兼容性与验证

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已在 macOS 15.7.7 上验证保存失败恢复及页面顶部避让；macOS 26.6.2 的实际交互仍需实机复测。
- 已安装旧版的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
