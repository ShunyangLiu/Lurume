# Lurume v0.0.10

发布日期：2026-09-09

## 双翻译对照

- 右侧翻译面板和翻译设置新增“系统 + 大模型”选项，同一段选文的两份译文上下展示，互不覆盖，并记住引擎选择。
- 系统翻译与大模型翻译可分别翻译、停止、重试和复制。开启自动翻译后，两种引擎会同时处理选文。
- 大模型翻译失败或停止时保留系统译文；切换选文、切换论文或清空翻译时同步清理旧结果。
- 大模型翻译仍使用已配置的服务，首次发送前保留服务授权确认。

## 文件夹导入与文献集修复

- 修复目录标识缺失或为 0 时，不同文件夹可能被误认为同一来源、导入到旧文献集的问题。旧目录改名后新建同名目录，可以分别识别。
- 修复导入预览中取消目录勾选后无法重新勾选的问题，并明确目录勾选与导入位置的含义。
- 新建文献集增加“取消”按钮；空名称按回车、离开输入框或切换文献集时取消创建，无需先命名再删除。
- 编辑文献集名称时，删除键不再触发所选父文献集的删除操作。

## 兼容性

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已安装旧版的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
