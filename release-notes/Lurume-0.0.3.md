# Lurume v0.0.3

发布日期：2026-08-30

## 主要变化

- 新增 Zotero 风格的文献集、未分类视图和独立文献库模式，支持表格浏览、多选、拖放与批量整理。
- 高亮可以附加纯文本笔记；PDF 页面长期保留可拖动的笔记标志，点击后在原文旁打开浮动编辑卡片。
- 设置统一收纳文献库、翻译与软件更新选项，阅读界面保持专注。
- 加入 Sparkle 安全更新基础设施和“检查更新…”入口。`v0.0.3` 是需要手动安装的引导版本，后续版本可以在应用内检查并确认安装。

## 修复与改进

- 修复 PDF 右键菜单崩溃，并精简、汉化与当前选区相关的操作。
- 修复文献库与阅读模式切换时检查器消失、来源上下文丢失和空文献集布局错位的问题。
- 优化文献筛选状态、默认排序、阅读状态反馈和侧栏控件布局。
- 更新检查失败不会阻塞阅读；后台失败保持低干扰，安装前会保存页码、文献库修改和笔记草稿。

## 兼容性与安装

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 当前安装包没有 Apple Developer ID 签名或苹果公证。首次安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
- Lurume 不会写回原 PDF；文献库、高亮、笔记和设置继续保存在本地。
