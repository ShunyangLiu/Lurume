# Lurume v0.0.12

发布日期：2026-09-09

## 连续系统翻译修复

- 修复“系统 + 大模型”第一次系统翻译成功、后续更换选文却启动超时的问题。
- 连续选文保留系统会话配置并正确触发下一次翻译；停止、清空或切换模式后按需重新建立会话。

## 大模型翻译连接复用

- 连续请求复用 XPC 连接和网络会话，减少重复启动及建连开销；空闲约 30 秒后回收。
- 请求的 Key、流式解析、超时和取消仍独立处理，停止一个请求不会中断其他请求。
- 网络会话继续禁用 Cookie、响应缓存和共享凭据存储，跨来源重定向仍被拒绝。

## 兼容性

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已安装旧版的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
