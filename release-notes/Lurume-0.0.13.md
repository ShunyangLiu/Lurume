# Lurume v0.0.13

发布日期：2026-09-09

## 阅读控件显示

- 页码、翻页和缩放控件移到 PDF 阅读区域顶部，避免被系统工具栏折叠进右上角的双箭头菜单。
- 阅读区域较窄时，控件自动分成两行显示。

## 笔记图标重绘

- 调整黄色笔记图标移动后的重绘逻辑，清理旧位置并刷新新位置，处理拖动后残影问题。

## 兼容性与验证

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已在 macOS 15.7.7 上完成测试及宽、窄布局检查；macOS 26.6.2 的实际显示效果尚待实机验证。
- 已安装旧版的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
