# Lurume v0.0.14

发布日期：2026-09-09

## 笔记图标显示

- 黄色笔记图标改为独立的页面覆盖视图，不再参与 PDF 注释绘制，处理移动后旧位置残留图标的问题。
- 保留拖动、位置保存和点击编辑，并随页面缩放及旋转定位。

## 阅读工具栏

- 移除顶部整行工具栏，改为阅读区域底部居中的小浮动条。
- 页码、翻页和缩放保持可见，较窄的阅读区域使用两行布局。

## 兼容性与验证

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已在 macOS 15.7.7 上通过连续移动像素清空、缩放、旋转及宽窄布局检查；macOS 26.6.2 的实际效果仍需实机复测。
- 已安装旧版的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
