# Lurume v0.0.15

发布日期：2026-09-09

## 笔记输入提示修复

- 笔记编辑框获得焦点后立即隐藏占位提示，避免中文输入法组词期间提示文字与输入内容重叠。
- 为笔记编辑框补充辅助功能名称。

## 兼容性

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已在 macOS 15.7.7 上构建和测试；macOS 26.6.2 的输入法显示效果仍需实机复测。
- 已安装旧版的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
