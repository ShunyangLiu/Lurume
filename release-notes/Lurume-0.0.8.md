# Lurume v0.0.8

发布日期：2026-09-05

## 笔记与文献库数据保护

- 修复高亮撤销、重做后，后来保存的笔记和笔记标记位置可能丢失的问题；恢复时保留删除前的最新内容。
- 退出应用或安装更新前会检查文献库是否保存成功。保存失败时默认返回检查，避免未保存的标题、阅读进度等修改在重启后丢失；只有明确选择丢弃时才继续退出。
- 修复重新关联 PDF 保存失败后，界面状态与磁盘记录不一致的问题。关联信息保存成功后才更新当前状态，失败后可以安全重试。

## 兼容性

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已安装旧版的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
