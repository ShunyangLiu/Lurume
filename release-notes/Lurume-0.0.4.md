# Lurume v0.0.4

发布日期：2026-08-30

## 主要变化

- 完成首个可通过 Lurume 内置“检查更新…”获取的稳定版本，用于验证从 `v0.0.3` 到 `v0.0.4` 的完整升级链路。
- 更新窗口继续使用 Sparkle 标准界面，展示中文更新说明，并在用户确认后才下载、安装和重启。
- 发布包、更新源和更新说明均使用同一套 EdDSA 信任根签名，并在公开前后核对版本、长度和内容哈希。

## 修复与改进

- 完善本地两阶段发布流程，使 GitHub Release 已成功但 Pages 尚未部署时可以安全重试，不覆盖既有标签或安装包。
- 更新检查、下载或验证失败不会影响 PDF 阅读、翻译、高亮、笔记和文献库操作。
- 安装重启前继续保存当前页码、文献库修改和笔记草稿。

## 兼容性与安装

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已手动安装 `v0.0.3` 的用户可以从应用菜单选择“检查更新…”，确认后升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
- 本版本不修改文献库、高亮或笔记的数据格式，也不会写回原 PDF。
