# Lurume v0.0.11

发布日期：2026-09-09

## 双翻译系统会话修复

- 修复“系统 + 大模型”模式下可能出现“系统翻译会话启动超时”的问题。
- 系统翻译统一使用一个会话入口；切换翻译模式时重新建立对应的系统会话，避免沿用旧会话导致新请求无法启动。
- 保留系统与大模型两份译文的独立展示、停止、重试和复制能力。

## 兼容性

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已安装旧版的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
