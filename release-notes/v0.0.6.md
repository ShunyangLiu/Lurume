# Lurume v0.0.6

发布日期：2026-09-05

## 翻译可靠性

- 修复 Apple 系统翻译在相同语言组合下重复翻译时可能一直等待的问题。
- 系统翻译现在会主动准备尚未下载的语言资源，并为会话启动、资源准备和翻译响应增加超时保护。
- 系统翻译进行中现在可以手动停止；超时或停止后可以直接重试，不会被旧请求结果覆盖。

## 大模型翻译速度

- 新增默认开启的“低延迟翻译参数”，短选区使用 1,024 token 输出预算和零温度，长段落会按长度自动提高预算，最高 8,192 tokens，兼顾响应速度与论文段落完整性。
- 使用不支持这些可选参数的 OpenAI-compatible 服务时，可在“设置 → 翻译”中关闭该选项。
- 保持现有 Base URL、模型、API Key 和自定义学术提示词不变；升级后无需重新配置。

## 兼容性

- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已安装 `v0.0.5` 的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”中手动允许打开。
