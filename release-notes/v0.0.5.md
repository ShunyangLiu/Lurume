# Lurume v0.0.5

发布日期：2026-09-01

## 主要变化

- 新增原生 OpenAI-compatible 大模型翻译。可在“设置 → 翻译”中配置一套自己的 Base URL、
  模型与 API Key，对当前选中文字进行流式翻译，并可随时停止生成。
- 新增文件夹批量导入。Lurume 原位引用用户选择目录中的 PDF，并把已有目录结构映射为可嵌套
  的文献集；导入和重导都不会修改来源 PDF。
- 新增 Zotero 本地迁移。通过 Zotero Local API 只读预览个人文库与可见群组文库，把确认的
  PDF 复制到用户单独授权的目标目录，并迁移书目元数据、嵌套文献集和多重归属。
- 文献库升级到 schema v5，支持嵌套文献集、结构化创作者、日期、DOI、URL、标识符、标签等
  引用元数据，同时保留旧文献、页码、阅读状态、高亮和笔记。

## 安全与数据边界

- Apple 系统翻译仍是默认引擎。自定义服务只接收当前规范化的选中文字，不发送论文标题、
  文件路径、页码、整页正文、高亮或笔记；API Key 只保存在 macOS 钥匙串。
- 翻译请求和 Zotero Local API 请求分别由两个专用 XPC 服务发出。主 App 没有通用网络权限，
  两个 XPC 没有文件、钥匙串或服务端权限。
- Zotero 迁移采用先暂存、双端 SHA-256 校验、再原子发布的事务流程；最终命名绝不覆盖目标
  目录中的既有文件，取消、保存失败和崩溃恢复遵循“无法证明归属就不删除”的保守规则。
- 删除 Lurume 中的文献或文献集不会删除文件夹来源 PDF 或 Zotero 迁移目标中的副本。

## 使用体验与兼容性

- 文献集现在可以创建子级、拖动整理、移到顶层、递归显示与递归删除；组织操作支持完整撤销。
- 元数据编辑器和搜索已覆盖扩展引用字段，手动编辑或清空的字段在重导后保持优先。
- 需要 macOS 15 或更新版本，同时支持 Apple Silicon 与 Intel Mac。
- 已安装 `v0.0.4` 的用户可以通过 **Lurume → 检查更新…** 升级到本版本。
- 当前安装包没有 Apple Developer ID 签名或苹果公证；全新安装仍需在“系统设置 → 隐私与安全性”
  中手动允许打开。
